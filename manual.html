User manual

LightDori guide

Everything from your first patch list to console handoff. Written for lighting designers, production electricians, and shop teams — no prior LightDori experience assumed.

1. What LightDori does

LightDori is a desktop workspace for lighting production data. Instead of juggling a spreadsheet, a drawing file, and a console show file, you keep one fixture list and let LightDori produce the paperwork and the exports each department needs.

It runs on Windows and macOS, works offline, and is built for theatre, touring, and rental shop workflows.

The core loop

  1. Build or import your fixture list in the Sheet.
  2. Assign universes and addresses, and check for conflicts.
  3. Export a patch document PDF for the shop and the booth.
  4. Hand the data off to Vectorworks or a lighting console.

What is in the app

  • Sheet — the fixture table: channels, addresses, types, positions, colours.
  • Magic Sheet — a visual channel layout you can print or use at the console.
  • Script / Cue Sheet — mark cues against an imported script and build a cue or scene breakdown.
  • Moodboard — a free canvas for references, notes, and looks.
  • Colour, Gobo, GDTF, Cable, Calendar — reference libraries and planning tools.
  • Workflow & PDF Store — collect every PDF you export and merge them into one package.
  • Console — connect to ETC Eos or grandMA to exchange patch and cue data.

2. Getting started

Signing in

LightDori asks for your account the first time you launch it. Enter your email and password and press Sign In. If you do not have an account yet, switch to the SIGN UP tab and create one with your name, email, and a password.

Tick Remember me to stay signed in on that computer. Your licence is checked online, but LightDori keeps working offline for about a week after the last successful check.

The start hub

After signing in you land on the hub. It has three large cards:

  • CONTINUE WORK — reopens the project you used most recently.
  • OPEN FILE — browse for an existing .ld project or a data file.
  • NEW FILE — starts the new project guide described below.

The right-hand side shows News from us and your three most Recent files. Click a recent file to jump straight back into it.

Creating a new project

NEW FILE opens a five-step guide. You can press Skip at any point and fill the details in later.

  1. Name the project — the show or event name.
  2. Set the venue info — venue name, stage size (black box through to festival), expected channel count, and optionally a floor plan in PDF, DXF, or image form.
  3. Choose fixture setup — Start blank, Import fixture data, or Use sample data.
  4. Pick starting panels — which workspaces open with the project: Sheet, Magic Sheet, Scripts / Cue Sheet, Moodboard.
  5. Ready to start — a summary. Press Start project.
Tip

None of these choices lock you in. Stage size and channel count only set sensible defaults, and you can open any panel later.

Finding your way around

The workspace has two navigation layers. Large cards in the middle open the main modules — Sheet, Scripts / Cue Sheet, Moodboard, Magic Sheet — with smaller cards beside them for Colour, Gobo, GDTF, Cable, Calendar, and Workflow.

The narrow rail down the left side stays available everywhere:

  • Home, Help, Alerts — return to the cards, read help for the panel you are in, and see warnings about your data.
  • Collab, Profile, Settings — shared sessions, your account, and app preferences.
  • Console, Store — the console link and the PDF Store.
  • Snap, Album — drag a rectangle to capture part of the screen, then find those captures in the album.

Saving your work

Projects are saved as a single .ld file. Use Ctrl + O to open, Ctrl + S to save, and Ctrl + Shift + S to save a copy. On macOS use Cmd instead of Ctrl. An asterisk in the title bar means you have unsaved changes.

Please note

There is an Auto save preference in Settings, but do not rely on it as your only safety net — save manually before big edits, imports, and exports.

3. Sheet workspace

The Sheet is the fixture table at the heart of the app. Everything else — the patch PDF, the magic sheet, the Vectorworks exchange, the console push — reads from it.

Columns are not fixed. They come from whatever file you imported, so a sheet from an MVR looks different from one built out of a shop spreadsheet. Typical columns are Channel, Purpose, Position, Unit Number, Instrument or Device Type, Universe, Address, Dimmer, Circuit, Colour, and Gobo.

The toolbar

  • Search — type to narrow the table as you go; press Enter to apply immediately.
  • Filter — show only rows where one column contains a piece of text.
  • Sort — reorder the table by any column, A→Z or Z→A.
  • Edit — unlocks the table. Adding, deleting, and cell editing only work while this is on; press it again to finish.
  • Add fixture / Delete selected rows — available in edit mode.
  • Undo / Redo — step back and forward through sheet changes.
  • Universe map — a 512-channel grid per universe showing what is used, free, or double-patched.
  • Auto universe — assign universes and addresses to many fixtures at once.
  • Fixture type summary — a side panel counting how many of each fixture type you have.
  • Vectorworks — opens the sync panel described in section 10.
  • Export — data file, patch document PDF, XML, or MVR.

Selecting and editing

  • Select a row by clicking it. Hold Ctrl (Cmd on macOS) to add rows one at a time, or Shift to select a range.
  • Tick the checkbox at the start of a row to include it in an export. The checkbox in the header ticks everything currently visible — which is why filtering first makes exporting much easier.
  • Edit a cell by turning on Edit and double-clicking it. Enter commits your change, Esc cancels it.
  • Colour and gobo cells open a picker on double-click instead of a text box, so you choose from the real gel and gobo libraries.
  • Reorder columns by dragging their headers, and sort by clicking a header.
Tip

Selecting a row and ticking a row are two different things. Selection is for editing and Auto universe; the tick decides what ends up in your export.

Adding fixtures by hand

Turn on Edit, press Add fixture, and fill in the fields you care about. The dialog covers far more than the basics — purpose, position, unit number, dimmer, circuit number and name, system, DMX footprint, field and beam angle, wattage, weight, frame size, gobos and gobo rotation, plus six free-form user fields. Leave anything you do not need blank.

Patching with Auto universe

Auto universe fills in a run of addresses for you instead of typing them one by one.

  1. Choose a Target: the rows you selected, everything currently visible, only unpatched rows, or the whole sheet.
  2. Set the Start universe and Start address (1–512).
  3. Set an Offset if you want to leave gaps between fixtures.
  4. Press Apply.

Then open Universe map and check the summary at the top of each universe tab. It counts used and free channels and flags conflicts, and hovering any square tells you which channel it is.

4. Patch document PDF

This is the paperwork the shop and the booth actually hold — an instrument schedule or patch list, laid out for print.

Making one

  1. In the Sheet, tick the rows you want. Filter first if you only need one position.
  2. Choose Export → Patch document PDF.
  3. Pick your columns. Select all and Clear work on the whole list, and Up / Down set the order they print in.
  4. Or skip that and set Schedule preset to Instrument Schedule, which selects and titles the standard columns for you.
  5. Set the page up, fill in the header block, then press Update preview to see it.
  6. Press Export PDF.

Page and layout options

  • Paper size — A4, Letter, A3, or Legal.
  • Orientation — portrait or landscape. Wide schedules read much better in landscape.
  • Table style — Simple, Modern, or Minimal.
  • Row separator — draw a heavier line every few rows so eyes do not slip across the page.
  • Font size — 7 to 14 pt. Drop it to fit more columns on one page.

The header block

Set a Title (it defaults to “Lighting Device Patch List”), a Date, and a Note for revision or department information. You can add a Logo, and switch the whole header block or the total-count Summary line off if you want a bare table.

How the instrument schedule is organised

With the Instrument Schedule preset, fixtures are grouped by Position and sorted by Unit Number within each group. Every group gets its own heading and a repeated column header row, so a page torn out of the middle still makes sense. Fixtures with no position are collected under “(No Position)”.

Tip

The preview only refreshes when you press Update preview. If it says Pending, what you are looking at is out of date.

Exported PDFs are collected in the PDF Store — see section 9 for downloading and merging them.

5. Magic Sheet

A magic sheet is a picture of your rig rather than a table — groups of channel bubbles laid out the way you think about the stage.

LightDori builds a first draft from your fixture data automatically. Change Group by in the sidebar to organise cells by Purpose, Position, Colour, Instrument, or Focus.

Moving around the canvas

  • Pan by dragging empty canvas.
  • Zoom with the mouse wheel, or the zoom controls in the corner.
  • Select a cell with a single click; double-click to open it for detailed editing. Esc closes it again.
  • Move bubbles by dragging them, or drag across the canvas to box-select several at once.

Styling cells and bubbles

With a cell selected you can rename it, set its header colour, change the bubble scale and the slot grid, and drop in a background image (a plan or section works well) with an opacity slider. The direction pad points teardrop bubbles the way the fixtures actually face, and Auto direction from position guesses that from your position names.

Select a single bubble to change its channel number, or override its scale and direction independently of the rest of the cell. Reorder cells by dragging them in the sidebar list.

Exporting

Export PNG gives you a flat image for a console or a chat message. Export PDF opens a separate print layout where you choose which cards appear, how many columns and rows fit on a page, paper size, margins, and whether to print a header block and fixture details. Press Update preview, then Export PDF.

6. Script & cue sheet

Put the script on one side and your cues on the other, and mark cues where they actually happen.

  1. Import or replace the script from the script tools.
  2. Click a page to place a cue marker; click the marker again to remove it. Zoom in and out, or collapse pages, to work at a comfortable size.
  3. Add cues, scenes, and acts in the table beside it, and turn on Edit to change numbers, names, and timing. Undo and redo are available throughout.
  4. Switch between the cue sheet and a scene breakdown, and between table and card views, depending on whether you are working or presenting.
  5. Use Sync markers after editing the script so markers stay on the right pages.

Export cue document produces a PDF in the same layout tool as the patch document. Export cue data writes an ETC ASCII (.asc) file you can load into an Eos-family console.

7. Moodboard

A free canvas for the visual side of the conversation: references, colour ideas, sketches, and notes you want to show a director or a designer.

The toolbar covers Select, Add images, Text, Draw, Shape, and a Colour circle for gel ideas, plus page settings, undo, redo, and remove. Right-click an object to bring it forward or send it backward.

Hold Space to pan, Delete to remove the selection, and use Ctrl + C / V / Z / Y for copy, paste, undo, and redo. Export the board as PNG or PDF when you are done.

8. Colour, gobo & fixture libraries

Colour

Search LEE and ROSCO gels by code, name, or hex value, or switch to In use to see only the colours already in your rig. Opening a swatch shows its technical data and similar colours from other brands — useful when a shop is out of stock and you need a substitute.

Gobo

Browse gobo folders, preview the patterns, and assign them to slots on your fixtures. Assigned gobos appear as thumbnails in the sheet and print in your patch document.

GDTF

Look through the GDTF catalogue or your own local files to check modes, channel layouts, and 3D models before you commit to a fixture. You can also create and save your own .gdtf definitions.

Cable

Plan power and DMX runs on a routing canvas. Filter by all, power, or DMX, place devices, connect them, and read off the totals as you go.

Calendar

A simple month view for load-in, focus, tech, and strike dates attached to the project.

9. Workflow & PDF Store

PDF Store

Every PDF you export is collected in the Store on the left rail rather than dropped straight into a folder. Open it to see thumbnails of everything you have produced for this project.

  • Click a thumbnail to page through the document, download it, or delete it.
  • Double-click the name to rename it — worth doing before you send a package out.
  • Merge combines documents into one file. Press Merge, click the PDFs in the order you want them, then Confirm. You need at least two.
Tip

This is how you build one production pack: instrument schedule, magic sheet, cue sheet, and moodboard merged into a single PDF to send out.

Workflow

The Workflow canvas is a map of your paperwork. Each node stands for a document — patch, magic sheet, cue sheet, moodboard, floor plan, colour, export — and shows whether a PDF has been produced yet, so you can see at a glance what is still missing. Double-click a node to jump to the workspace that makes it, and merge by workflow order when everything is ready.

10. Vectorworks sync

LightDori and Vectorworks pass fixture data back and forth through one shared file, so the drawing and the paperwork stop drifting apart.

Where the exchange file lives

System Exchange file
Windows %USERPROFILE%\Documents\LightDoriExchange\ld_vw_exchange.json
macOS ~/Documents/LightDoriExchange/ld_vw_exchange.json

Both applications read and write that one file. Nothing goes over the internet, and you do not need the two programs on the same screen.

Sending your sheet to Vectorworks

Open the Vectorworks panel from the Sheet toolbar and press Sync Now. LightDori writes every fixture to the exchange file and confirms how many devices it sent. The Vectorworks side picks the change up and updates the drawing.

Bringing Vectorworks changes back

Export from Vectorworks first, then press Import to LightDori. You will be asked how to apply it:

  • Merge — matches fixtures already in your sheet, updates them, and adds anything new. This is the safe choice and what you want almost every time.
  • Overwrite — throws away the current sheet and replaces it with whatever Vectorworks sent. Only use this when you want the drawing to win outright.

Live sync

Turning Live sync on keeps both sides watching the exchange file: edits in the sheet are pushed out a moment after you make them, and changes coming from Vectorworks are merged in automatically. Leave it off when you want to review every change by hand.

Please note

Matching works on a hidden unique ID that each fixture carries. Fixtures arriving from Vectorworks without one are skipped silently, so if a handful of fixtures never appear, that is the first thing to check.

When it does not work

  • “Exchange file not found” — nothing has been written yet. Export from Vectorworks, or press Sync Now once from LightDori.
  • Fixtures missing after import — those fixtures had no unique ID. Re-export them from Vectorworks.
  • Vectorworks does not refresh — on Windows LightDori nudges it with Ctrl + Alt + Shift + U, which needs Vectorworks open. On macOS, refresh from the Vectorworks side yourself.

11. Console connection

Connect over the network to pull a patch off the console, push one to it, or read the cue list — no USB stick walk to the booth.

Supported consoles

Console Protocol Default ports Notes
ETC Eos / Ion / Nomad OSC 8000 / 8001 Pull patch and cue data
grandMA2 Telnet 30000 Pull and push patch
grandMA3 OSC 8000 / 8001 Limited — patch pull not available

Setting up an Eos console

  1. Open Setup → System → Show Control → OSC.
  2. Enable OSC RX and OSC TX.
  3. Set OSC UDP RX Port to 8000.
  4. Set OSC UDP TX Port to 8001.
  5. Note the console's IP address — you will type it into LightDori.

Setting up a grandMA console

  1. Open Setup → Console → Global Settings.
  2. Set Telnet to Login Enabled.

Connecting from LightDori

  1. Open Console from the left rail.
  2. Choose the console type, type its IP address, and leave the ports at their defaults unless your setup says otherwise.
  3. Press Connect.

Once connected, the Patch tab pulls the patch off the console or sends yours to it, the Cue Sheet tab lists sequences and cues, and the Command tab lets you type raw console commands and watch the replies.

Please note

Pushing a patch to an Eos console is not supported yet — pull from Eos, and use the ASCII (.asc) export to go the other way. On grandMA3, reading the patch is not available either.

When it will not connect

  • Eos does not answer — the console is off, the IP is wrong, or Show Control OSC is not enabled. Check you are on the same network.
  • grandMA2 refuses the connection — Telnet is not set to Login Enabled, onPC is not running, or a firewall is blocking port 30000.
  • Patch sync times out — the connection dropped, or the console is busy. Reconnect and try again.

12. Import & export

The quickest way to import is to drag a file onto the LightDori window. Everything is also available from File → Import and File → Export.

What you can bring in

  • CSV, Excel (.xlsx, .xls, .xlsm) — shop lists and spreadsheets. Only the first worksheet is read.
  • JSON, XML — including grandMA2 XML and LightDori's own exports.
  • MVR — fixture packages from Vectorworks and other MVR-capable tools, with their GDTF definitions.
  • ASCII (.asc) — ETC Eos show files. LightDori asks whether you want the patch, the cue data, or both.
  • LightDori project (.ld) — a whole project.

Common column names are tidied up on the way in — a Patch column written as 1.001 is split into universe and address, and names like FixtureType and Ch ID are mapped onto LightDori's fields.

What you can send out

  • CSV, Excel, XML, plain text — for spreadsheets and other software.
  • MVR — back to Vectorworks and friends. If the sheet came from an MVR, the original 3D and GDTF assets are preserved.
  • ASCII (.asc) — a cue sheet for an Eos-family console.
  • PDF — patch documents, magic sheets, cue documents, and moodboards.
Tip

Exports only include ticked rows, and you pick the columns each time. If an export comes out empty, no rows were ticked.

After any import, check the universe map for address collisions before you send the data to a console.

13. Settings

Open Settings from the left rail.

  • Theme — light or dark. The change previews straight away.
  • Auto save and its interval — 1 to 60 minutes.
  • Show tooltips — the little labels on toolbar icons.
  • Confirm before deleting — worth leaving on.
  • Remember window size and position — reopen where you left off.
Please note

Nothing sticks until you press Save settings. Closing the panel without saving puts the theme back the way it was.

14. Account & collaboration

Your account

Open Profile from the left rail to change your display name and photo, and to see your account status and licence expiry. Log out is here too.

Licence

Licence keys look like ABCD-1234-EFGH-5678. Your licence is confirmed online when you sign in; if you are away from the internet, LightDori keeps running on the last successful check for about a week.

Working with other people

Collab on the left rail creates shared sessions and invites people by email. Each person is an owner, an editor, or a viewer, and viewers can look but not save. While a session is active the project is stored with the session rather than as a local file, and you can restore an earlier version from its history.

15. Troubleshooting

Fixtures and patching

  • An export came out empty. No rows were ticked. Tick rows, or use the header checkbox to tick everything visible.
  • A CSV would not open. Re-save it as UTF-8 or Excel format. Korean encodings are handled, but unusual ones may not be.
  • An MVR failed to import. The archive is incomplete. Re-export it from the original software.
  • Two fixtures share an address. Open the universe map — conflicts are flagged in the summary for each universe.

Sync and consoles

  • Vectorworks import brought nothing back. Export from Vectorworks first — the exchange file has to exist before LightDori can read it.
  • Some fixtures never arrive. They are missing their unique ID. Re-export them from Vectorworks.
  • The console will not connect. Check both machines are on the same network, the IP is right, and OSC or Telnet is enabled on the console.

Printing and display

  • The preview looks wrong. Press Update preview — it does not refresh on its own.
  • Columns run off the page. Switch to landscape, drop the font size, or print fewer columns.
  • The interface looks the wrong size. Restart LightDori after changing your display scaling (125%, 150%, and so on).
  • Something looks stale after an update. Quit LightDori completely and open it again.
